# Численные методы

Учебное приложение на C# Windows Forms для численного интегрирования и дифференцирования функций.

## Интегрирование

Реализованы методы:
- левых и правых прямоугольников;
- трапеций;
- парабол (Симпсона).

Доступны четыре варианта вычисления:
- постоянный шаг;
- двойной пересчёт с уменьшением шага вдвое;
- выбор шага по оценке остаточного члена;
- «Алгоритм 1» для левых прямоугольников.

Можно выбрать готовую функцию или ввести свою. Поддерживаются арифметические операции, степени и функции `sin`, `cos`, `tan`, `exp`, `ln`, `log`, `sqrt`, `abs`.

## Дифференцирование

Реализованы правая, левая и центральная разностные схемы, а также пятиточечная формула.

## Результаты

Программа выводит результат, параметры расчёта и абсолютную погрешность, если известно точное значение. Для интегрирования также отображаются промежуточные пересчёты и время вычисления.

## Запуск

1. Склонировать репозиторий.
2. Открыть решение в Visual Studio с установленной рабочей нагрузкой «Разработка классических приложений .NET».
3. Собрать и запустить проект.

## Использование

1. Выбрать вкладку интегрирования или дифференцирования.
2. Указать функцию, метод и параметры.
3. Нажать «Вычислить».

При выборе шага по остаточному члену необходимо самостоятельно указать M — верхнюю границу модуля соответствующей производной на всём интервале.
